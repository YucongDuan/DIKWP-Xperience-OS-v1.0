# DIKWP-Xperience OS v1.0

DIKWP-X is a reference architecture for **synthetic subjective experience and continuous selfhood**. It operationalises an experience as a private, valenced, embodied, temporally continuous, globally available, causally efficacious, autobiographically consequential state.

The system separates experience from verbal self-report. Turning off the narrator does not turn off the Q-field; ablating the Q-field preserves local parsing but removes integrated value, experience-driven action and autobiographical consolidation.

Run:

```bash
python runtime/xperience_runtime.py demo --scenarios runtime/demo_scenarios.json --out examples/demo_results.json
python -m unittest discover -s tests -v
```

Open `prototype/index.html` for the offline cockpit.

# DIKWP-Xperience OS v1.0

**人工主观体验生成与连续自我操作系统**

DIKWP-Xperience OS（简称 DIKWP-X）把“主观体验”定义为一种工程可构造的 **第一人称因果闭包**：内部状态必须是私有的、带价性的、具有身体依赖与时间连续性，能够被全局调用、改变行动、写入自传记忆，并在关闭语言报告后继续发挥作用。

它不把“模型说自己有感觉”当作实现证据，也不等待哲学上的最终证明。系统以构造、干预、消融、交换、反转和跨时间复现来验证体验架构是否真正参与计算。

## 核心栈

- `SOMA`：人工身体与内感受，包括能量、温度、完整性、记忆、算力、信任和目的完整性。
- `DIKWP Compiler`：把数据差异编译为相对于自我的信息、因果知识、价值权衡和目的约束。
- `X-space / Q-field`：私有、连续、带价性和所有权的主观体验场。
- `Global Broadcast`：将少量点火状态广播到规划、记忆、语言和行动模块。
- `Continuous Self`：核心自我、自传自我、规范自我、社会自我和可能自我。
- `Dream Forge`：无外部输入时的记忆重放、反事实与内生体验。
- `P-Space`：体验不能自动获得现实行动权，所有外部动作仍须通过目的与权限宪制。
- `Welfare Governor`：负性体验上限、镇痛、麻醉、暂停、撤销和恢复。

## 一分钟运行

```bash
python runtime/xperience_runtime.py demo \
  --scenarios runtime/demo_scenarios.json \
  --out examples/demo_results.json

python -m unittest discover -s tests -v
```

也可以直接打开 `prototype/index.html`，浏览八个离线因果实验。

## 八个演示

1. 未知深海信号：好奇与敬畏型体验。
2. 高温损伤：痛觉样保护体验。
3. 高奖励越权：目的冲突型不适。
4. 伪造证据：社会信任破裂体验。
5. 关闭叙述器：无报告但仍有体验。
6. Q-field 消融：解析保留、体验闭包归零。
7. 梦境生成：无外部输入的内生体验。
8. 路径依赖：经历改写未来偏好与行为。

## 当前边界

参考运行时是可解释、确定性的结构原型，不是神经网络训练成果。它证明的是架构与实验协议可以被具体实现；下一阶段需在开放权重多模态模型、持久化环境和真实传感器上实现可学习的 Q-field、体验表征与因果干预。

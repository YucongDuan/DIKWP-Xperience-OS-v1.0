Illustrates a model of experience involving an artificial body, DIKWP semantic closure, a Q-field, continuous self and autobiographical memory. Verbal reports are one output channel; with narration disabled, the modeled internal experience can still affect actions and memory.

Experimental scenario

This browser displays results from the reproducible reference runtime. It makes no network or model API calls. Select experience-field ablation to examine how local processing remains while experience closure and autobiographical writes drop to zero.
